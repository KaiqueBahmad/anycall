# AnyCall docs

Documentation that applies to every implementation (Java, Python). How to
use each library lives next to it, in `implementations/<language>/USAGE.md`.

## Visuals

Standalone HTML pages: open them in a browser. GitHub shows `.html` files as
source, so clone the repo or download the file to view one.

| Page | What it shows |
|---|---|
| [Reaping](visuals/reaping.html) | What happens when a server dies mid-request: who notices, how long it takes, and what the caller gets. Includes a step-through simulator. |
