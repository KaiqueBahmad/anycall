    Who reaps it?

    Reaping only covers requests a server already took. One still sitting in its queue, with no server alive or none serving its method, just waits out the timeout.

    What the caller sees

    ServerLostError

    The server holding the request is gone. Carries that server's id. The request started and may have partly run; retry only if it's idempotent.

    TimeoutError

    The configured timeout ran out. Says nothing about the server: slow, lost just now, or never took the request.
