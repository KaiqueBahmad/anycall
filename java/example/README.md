# AnyCall Example Application

Aplicação de exemplo que demonstra o uso da biblioteca AnyCall.

## Pré-requisitos

1. Compilar e instalar a biblioteca AnyCall localmente:
```bash
cd ../lib
./mvnw clean install
```

2. Redis rodando localmente na porta 6379

## Executar

```bash
./mvnw spring-boot:run
```

A aplicação irá iniciar na porta 8080.
