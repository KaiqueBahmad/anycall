# AnyCall Library

Esta é a implementação da biblioteca AnyCall - uma biblioteca Redis-based para RPC em Java.

## Estrutura

- `src/main/java/dev/kaiquebt/anycall/` - Código fonte da biblioteca
- `pom.xml` - Configuração Maven da biblioteca

## Build

```bash
./mvnw clean install
```

Isso irá compilar e instalar a biblioteca no repositório Maven local.
